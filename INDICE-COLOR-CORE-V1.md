# INDICE - COLOR CORE V1

Este arquivo centraliza os materiais do Color Core v1.

---

## 1. Leitura recomendada

### 1. Aprovacao de gestao

Para leitura executiva e aprovacao das familias:

- `APRESENTACAO-COLOR-CORE-GESTAO-V1.md`

### 2. Candidato atual

Para ver o estado atualmente aprovado das familias, sem edicao:

- `color-core-candidato-atual.html`

### 3. Editor de ajuste fino

Para operacao, refinamento e exportacao do estado:

- `color-core-editor.html`

### 4. Avaliador rapido

Para comparar rotas e registrar notas por familia:

- `color-core-avaliacao.html`

### 5. Sintese de rodada

Para consultar a consolidacao intermediaria do processo:

- `color-core-sintese-1.html`

---

## 2. Papel de cada arquivo

### `APRESENTACAO-COLOR-CORE-GESTAO-V1.md`

Camada enxuta de aprovacao para gestao.

### `color-core-candidato-atual.html`

Preview estatica do estado atual aprovado.

### `color-core-editor.html`

Sandbox editavel para microajustes nas familias.

### `color-core-avaliacao.html`

Ferramenta de comparacao rapida com notas e exportacao.

### `color-core-sintese-1.html`

Consolidacao da primeira rodada de feedback.

### `color-core-familias.html`

Preview estrutural das familias em formato de sistema.

### `color-core-energia.html`

Exploracao isolada da familia Energia.

---

## 3. Fluxo de uso

Se a pergunta for **"o que foi aprovado?"**

- abrir `APRESENTACAO-COLOR-CORE-GESTAO-V1.md`

Se a pergunta for **"qual e o estado atual?"**

- abrir `color-core-candidato-atual.html`

Se a pergunta for **"quero mexer pessoalmente nas cores"**

- abrir `color-core-editor.html`

Se a pergunta for **"quero comparar opcoes antes de decidir"**

- abrir `color-core-avaliacao.html`

Se a pergunta for **"quero entender como chegamos ate aqui"**

- abrir `color-core-sintese-1.html`
