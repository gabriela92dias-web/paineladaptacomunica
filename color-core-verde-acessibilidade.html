Verde Core x Color Core

Convivencia acessivel

Preview visual do relacionamento entre os dois sistemas. Aqui o foco nao e aprovar cor, mas enxergar quais combinacoes funcionam bem para leitura e quais devem ser evitadas.

Como ler

  • Seguro = pode entrar como regra padrao.
  • Seletivo = funciona, mas depende do caso.
  • Evitar = nao usar como combinacao de leitura.

Regra-matriz

Verde Core como dono

Nesta camada de convivencia, o Verde Core governa estrutura e leitura. O Color Core entra como atmosfera ou acento, sem disputar o mesmo plano de propriedade.

Estrutura

Verde Core abre e fecha o plano.

Leitura

Texto principal continua no Verde Core escuro.

Atmosfera

Color Core ocupa campo, acento e pulso visual.

Evitar

Quando os dois sistemas competem pelo mesmo plano

Evitar competicao cromatica

Fundo verde escuro + bloco medio de Color Core

O fundo escuro nao deve receber centro, denso ou marca-texto do Color Core como massa. Fica poluido e disputa propriedade.

massa media nao usar
Evitar medio com medio

Verde medio repetindo medio do Color Core

Quando os dois sistemas brigam no mesmo peso medio, a composicao perde dono e vira ruido.

competicao sem hierarquia
Evitar marca-texto como fundo/texto

Marca-texto do Color Core como leitura principal

Marca-texto nao entra para segurar o plano. Ele deve ser destaque, nao base estrutural nem leitura pequena.

destaque nao fundo
Evitar densos em grande area

Denso + denso em area extensa

Centro, denso e marca-texto do Color Core devem ser parcimoniosos quando ocupam grandes massas, especialmente ao lado do Verde Core.
