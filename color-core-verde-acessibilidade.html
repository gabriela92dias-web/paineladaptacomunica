Verde Core x Color Core

Convivencia acessivel

Preview visual do relacionamento entre os dois sistemas. Aqui o foco nao e aprovar cor, mas enxergar quais combinacoes funcionam bem para leitura e quais devem ser evitadas.

Como ler

  • Seguro = pode entrar como regra padrao.
  • Seletivo = funciona, mas depende do caso.
  • Evitar = nao usar como combinacao de leitura.

Regra curta

Quem segura o texto

Quando os dois sistemas convivem, o Color Core funciona melhor como campo ou acento, enquanto o Verde Core mais escuro segura a leitura.

Seguro por padrao

green900 e neutros escuros sobre fundos do Color Core.

Uso seletivo

green700 sobre campos e tons mais claros do Color Core.

Evitar por padrao

texto do Color Core sobre fundos claros do Verde Core.
